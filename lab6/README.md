# Lab 6 Event Registration API

Alexey V — It302502 DS

A simple Spring Boot backend with three GET endpoints. Events are stored in memory.

## Requirements

JDK 21. Spring Boot 4.1.2 and Gradle wrapper 9.8.2 were generated by Spring Initializr.
The first run needs internet access to download Gradle and dependencies.

## Run

From the repository root:

```sh
cd lab6
./gradlew --console=plain bootRun
```

On Windows, use `gradlew.bat --console=plain bootRun` inside `lab6`.
In an IDE, run `kz.iitu.registration.EventRegistrationApplication`.
Stop the server with Ctrl+C. Build and run the generated startup test with `./gradlew build`.

## Endpoints

- http://localhost:8080/api/hello — welcome message from the service.
- http://localhost:8080/api/events — three events, each with an ID, title and location.
- http://localhost:8080/api/info — application name, course and semester from `application.properties`.

## Classes

- `EventRegistrationApplication`: starts Spring Boot and the web server.
- `RegistrationController`: handles HTTP requests and returns data as JSON.
- `EventService`: provides the welcome message and the in-memory event list.
- `EventInfo`: represents one event with private fields, a constructor and getters.

Spring creates EventService because of `@Service` and passes it into the controller constructor.
The controller does not create the service itself. `@Value` reads configuration values.
No database or frontend connection is used.
